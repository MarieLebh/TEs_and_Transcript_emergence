**Explanation of the data:**

* **MCTE_RechEtAl22.fasta.classified** = RepeatClassifier classification of the MCTE library (run: ``RepeatClassifier.sh``)
* **opt_DeepTE.txt** = DeepTE classification of the MCTE library (run: ``DeepTE.sh``)
* **MCTE_RFSB_results.txt** = TransposonUltimate (RFSB) classification of the MCTE library (run: ``TransposonUltimate.sh``)

MCTE library from Rech et al, 2022:  **https://doi.org/10.1038/s41467-022-29518-8 **
